# Ruta Madrid Pro

Aplicación web móvil para:
- Introducir pedidos por cliente.
- Pegar pedidos recibidos por WhatsApp.
- Calcular compra total y descontar stock.
- Separar proveedor principal, externo y pendiente.
- Poner precios individuales por cliente.
- Enviar TXT individual o general a Factumad mediante WhatsApp.
- Preparar facturas antes de la entrega.
- Comparar cantidad facturada con cantidad entregada.
- Generar correcciones.
- Archivar y limpiar cada ruta de forma segura.
- Funcionar sin conexión como PWA.

## Publicación en GitHub Pages
1. Crear un repositorio nuevo, por ejemplo `ruta-madrid-pro`.
2. Subir `index.html`, `manifest.json` y `sw.js` a la raíz.
3. En GitHub: Settings → Pages → Deploy from branch → main / root.
4. Abrir la dirección publicada desde el móvil y usar “Añadir a pantalla de inicio”.

Los datos se guardan en el navegador. Utiliza el botón de copia de seguridad regularmente.
