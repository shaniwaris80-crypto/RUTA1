# NEXORUTA CLOUD

Sistema nuevo e independiente para gestionar la Ruta Madrid.

## Incluye
- Rutas semanales
- Pedidos rápidos por códigos y vocabulario
- Compra consolidada
- Entregas con pedido, bajado, devuelto y facturable
- Factura según cantidad realmente entregada
- Cobros parciales y deuda
- Historial por cliente
- Productos, códigos y sinónimos
- Stock, gastos, semanas e informes básicos
- PWA multiplataforma
- Modo local y conexión a Firebase

## Configurar un Firebase nuevo
1. Crea un proyecto nuevo en Firebase Console.
2. Activa Authentication > Email/Password.
3. Crea un usuario.
4. Activa Firestore Database.
5. Pega `firestore.rules` en las reglas de Firestore y publica.
6. Registra una aplicación Web.
7. Copia la configuración en `firebase-config.js`.
8. Publica todos los archivos en GitHub Pages o Firebase Hosting.
9. Abre NEXORUTA CLOUD y pulsa `Conectar Firebase`.

## Importante
La versión entregada es una base funcional nueva. Para un uso fiscal definitivo conviene revisar numeración, series, rectificativas, conservación legal y datos fiscales con tu asesor.
